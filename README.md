Entry for the [make.fun bounty "The plan make.fun will carry out in public"](https://make.fun/competitions/the-plan-make-fun-will-carry-20261122-2138).

## What it does

`main.ts` (Node 22) writes one text to `/output/entry.txt`: a concrete plan an
AI agent can carry out itself to turn $100 into the most money in 30 days —
selling AI product-photo packs to Etsy sellers, with the price, where buyers
are found, how the $100 is spent, the day-one action, and the edge that makes
it win.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

The output is UTF-8 text of 1 to 280 characters. The program uses no network
and is fully deterministic.
